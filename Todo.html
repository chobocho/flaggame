🚩 청기 백기 게임 (TS + Canvas) 설계 문서

1. 프로젝트 개요

25년 전 오락실/TV에서 유행하던 클래식 '청기 백기' 게임의 웹 버전. 음성 명령(여성 목소리)에 따라 사용자가 키보드로 반응하는 체감형 순발력 게임입니다.

  • 기술 스택: HTML5 Canvas, TypeScript, Web Audio API / Web Speech API (TTS)
  • 렌더링: 100% Canvas API를 활용한 프레임 기반 렌더링 (DOM 요소 최소화)
  • 오디오: window.speechSynthesis를 사용해 한국어 여성 음성(ko-KR)으로 명령 하달

2. 코어 메커니즘 & 조작

동작 단축키 (키보드) 상태 변화
청기 올리기 Q Blue: UP
청기 내리기 A Blue: DOWN
백기 올리기 P White: UP
백기 내리기 L White: DOWN

* 명령이 끝난 후 제한 시간(예: 1.5초) 내에 요구되는 깃발 상태와 현재 상태가 일치해야 성공.

3. 시스템 아키텍처

  • GameEngine: requestAnimationFrame 기반 메인 루프, Delta Time 계산
  • StateManager: 대기 -> 명령 재생 -> 입력 대기 -> 판정 -> (반복/종료)의 FSM 관리
  • CommandGenerator: 난이도에 따른 논리적 명령 생성기 (단일, 연속, 부정형)
  • VoiceManager: Web Speech API 제어, 텍스트 파싱 및 발화 타이밍 동기화
  • Renderer: Canvas 컨텍스트 관리, 캐릭터/깃발/스코어/타이머 드로잉

4. UI/UX 개념도 (Canvas Rendering Target)

* 위 화면은 HTML5 Canvas API의 fillRect, arc, lineTo 등을 사용하여 구현됩니다.

5. 클로드(Claude) 구현 진행 TODO 리스트

클로드에게 아래의 단계를 순차적으로 요청하여 개발을 진행하세요.

  • Phase 1 프로젝트 스캐폴딩 및 게임 루프 구축

    Vite + TypeScript 환경 구성. index.html에 단일 <canvas> 요소 배치. requestAnimationFrame을 활용한 기본 GameLoop 클래스 및 화면 클리어 로직 작성.

  • Phase 2 Canvas 렌더링 시스템 (캐릭터 & 깃발)

    Renderer 클래스 구현. 양손의 상태(UP/DOWN)에 따라 깃발의 위치와 팔의 각도가 변하는 로직 작성. 청기(Left), 백기(Right) 색상 상수화.

  • Phase 3 명령어 생성기 (Command Generator) 논리 구현

    단순 명령("청기 올려")부터 복합 함정 명령("청기 올리지 말고 백기 내려")까지 텍스트를 생성하고, 해당 명령 수행 후 기대되는 최종 목표 상태(Target State)를 계산하는 로직 구현.

  • Phase 4 TTS (Web Speech API) 연동

    VoiceManager를 구현하여 Phase 3에서 생성된 텍스트를 한국어 여성 음성으로 재생. onend 이벤트를 캐치하여 사용자의 입력 대기 타이머(Timer)를 작동시키는 상태 동기화.

  • Phase 5 입력 처리 및 판정 로직

    키보드(Q, A, P, L) 이벤트를 수신하여 깃발 상태 변경. 타이머 종료 시점의 깃발 상태와 Phase 3의 목표 상태를 비교하여 Success/Fail 판정 및 목숨(Life) 차감 로직 구현.

  • Phase 6 난이도 커브 및 폴리싱

    스테이지가 오를수록 제한 시간이 짧아지고, 복합/부정 명령의 등장 확률이 높아지도록 조정. 성공/실패 시 Canvas 파티클 효과나 화면 흔들림(Screen Shake) 효과 추가.
