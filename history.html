최고 점수 기능 코드리뷰 및 수정

2026-07-03
  • 버그 수정 — 화면 가림: 최고 점수 패널이 게임오버의 최종 점수·재시작 안내, 일시 정지 안내, 시작 화면 단축키 안내를 덮던 문제 수정. 패널을 중앙 오버레이 텍스트 아래 ~ 하단 프롬프트 위 영역에만 배치하고, 공간에 맞게 표시 행 수를 자동 조정 (갤럭시 폴드7 펼친 화면처럼 논리 높이 700인 화면에서도 안전).
  • 버그 수정 — 점수 유실: IndexedDB 연결이 열리기 전(또는 열기 실패 시) 기록된 점수가 메모리 폴백에 들어갔다가 조용히 사라지던 경로 제거. HighScores가 지연 생성되는 단일 ready 프라미스로 자체 순서를 보장하도록 재설계.
  • 버그 수정 — 커넥션 누수: 게임오버마다 indexedDB.open()을 다시 호출해 커넥션을 누수하던 문제 수정(단일 공유 커넥션). onblocked 미처리로 프라미스가 영원히 대기하던 문제도 수정.
  • 버그 수정 — 폴백 미표시: DB 열기 실패 시 topScores를 빈 배열로 덮어 세션 점수가 절대 표시되지 않던 문제 수정(실패 시 기존 목록 유지, 폴백 목록 정상 표시).
  • 버그 수정 — 빈 목록 문구 위치: "아직 기록이 없습니다" 문구가 textBaseline 미설정으로 약 8px 아래로 밀리던 문제 수정.
  • 성능: 매 프레임(60fps) 반복되던 날짜/점수 문자열 포맷팅을 WeakMap 캐시로 대체. 0점 게임오버 시 불필요한 DB 재조회 제거. getTop()의 중복 배열 복사 제거.
  • 하드코딩 제거: 패널 레이아웃 매직 넘버(64, 92, 32, 반지름 12, 열 오프셋 30, 제목 간격 10/8 불일치)를 constants.ts의 명명 상수로 이동.
  • 테스트 추가: test/HighScores.test.ts — 정렬(점수 내림차순, 동점 시 최신 우선), 상위 N개 제한, 빈 목록 케이스 4건.
